1. Présentation du projet

Ce projet est une application web de gestion commerciale complète, développée dans le cadre du module Frameworks J2EE et Spring. Elle couvre l'intégralité du cycle commercial d'une entreprise : de la création du devis jusqu'à la facturation client, en passant par les commandes, les livraisons et le suivi des stocks.

L'application adopte une architecture API REST + SPA (Single Page Application), avec un backend Spring Boot exposant des endpoints JSON consommés par un frontend React.

Objectifs fonctionnels

  • Gestion des clients et fournisseurs
  • Catalogue articles avec alertes stock
  • Cycle Devis → Commande → Livraison → Facture
  • Achats fournisseurs (commande → réception → facture)
  • Mouvements de stock (entrée / sortie / ajustement)
  • Tableau de bord avec KPIs agrégés
  • Gestion des utilisateurs et des rôles

Contraintes techniques

  • Architecture en couches stricte
  • Relations JPA (@OneToMany, @ManyToMany, @OneToOne)
  • Authentification JWT stateless
  • Contrôle d'accès basé sur les rôles (RBAC)
  • Pagination Spring Data
  • Documentation Swagger/OpenAPI
  • Séparation DTO / Entité

private Set<Role> roles = new HashSet<>();

Numérotation automatique des documents

Le NumeroGeneratorService génère les numéros de documents au format PREFIX-ANNÉE-XXXX via une requête native SQL :

SELECT COUNT(*) FROM {table} WHERE {colonne} LIKE 'PREFIX-2026-%'
→ résultat + 1, formaté sur 4 chiffres : DEV-2026-0001

4. Sécurité — JWT & RBAC

4.1 Authentification JWT

L'authentification est stateless : aucune session serveur. Chaque requête porte un token JWT dans l'en-tête Authorization: Bearer <token>.

TokenDuréeUsage
Access Token15 minutesAccès aux endpoints API
Refresh Token7 joursRenouvellement du access token

4.2 Flux d'authentification

POST /api/auth/login → AuthenticationManager → CustomUserDetailsService
→ JwtUtil.generateToken() → { accessToken, refreshToken, roles, entrepriseId }

Requêtes suivantes :
Header: Authorization: Bearer <accessToken>
→ JwtAuthFilter → validateToken → SecurityContextHolder

Navigation et sécurité frontend

Le composant PrivateRoute redirige vers /login si l'utilisateur n'est pas authentifié, et vers /403 si son rôle est insuffisant. La page Utilisateurs n'est visible dans le menu que pour les ROLE_ADMIN.
